## 建议的推进顺序

1. 做阴影之前：04（Prepare / Record 拆分）→ 01（set 1 按材质取）→ 02（帧视图数据统一计算）+ 06；03 可以顺手一起做。
2. 做阴影时：shadow map 与 pass 间屏障归 `DoodleRenderPipeline`、前向 pass 的 set 0 改成绑定表（02）；投射物列表（01 + 11）。
3. 05 独立。树叶阴影要用 alphaCutoff 这类材质参数的话，提前到阴影之前。
4. 08、09、10：资产量上来或开始做流式加载时。
5. 07 放到最后；12、13、14 随手处理。

01、04、05 会改动现在定下的约定（「每个 pass 自管常量」「材质只有贴图」「set 1 按绘制项下标对齐」），动手前先定方案。
